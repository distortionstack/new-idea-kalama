# Selected case

Provisional case: `kalama-lab:type-c-shellshock`, CVE-2014-6271.

The repository documents it as an authorized isolated lab where Trivy should
identify vulnerable Bash and remediation is a package-manager action. It is
smaller and less occurrence-ambiguous than the Struts image. The case cannot
yet be approved for execution because the current Docker daemon is unreachable,
so image digest, scanner output, Metasploit module availability, package fixed
version, and network reachability remain unverified.

Execution approval must wait for Doctor to pass and for a read-only candidate
preflight to confirm all of those conditions.
